# 图片取景与成品图入口验收

2026-09-07，本机独立取景页实现与验收。

## 已实现

- 顶部“渲染出图”、导出面板“效果图”、成品图“导出设置”进入同一取景页。
- 保留同一个 Viewport/Canvas 实例；画布本身按输出比例布局，提交当前相机参数。
- 横版 1280×720 默认值；比例按实际宽高识别，非法尺寸禁止生成。
- 旋转、缩放、平移及正面/侧面/顶部/重置视角；窄屏预览与设置上下分区。
- 已有成品图统一查看器，旧绝对定位样式已移除；从取景页打开时可返回取景页。
- 生成中保留画面并禁用重复提交；失败保留构图、设置与上次成品图。

## 验证结果

- `npm test`：4 个测试文件、19 项测试通过。
- `npm run build`：TypeScript 与 Vite 构建通过；依赖注释和 bundle 体积提示仍存在。
- `npx tsx scripts/verify-image-composition.ts`：独立数据目录，固定三方块场景，不调用 AI。用相同相机计算 Three.js 投影三角形并裁切，再对照真实 Blender PNG 的 alpha 主体边界，容差为 2 像素。

| 场景 | PNG 尺寸 | 最大边界误差 |
| --- | --- | --- |
| 横版 | 640×360 | 1.55 px |
| 方形 | 512×512 | 0.84 px |
| 竖版 | 360×640 | 1.31 px |
| 竖版近景，主体越过画面边缘 | 360×640 | 1.53 px |

原始结果：`data/image-composition-validation/framing-result.json`。这是几何构图验证，不表示网页与 Blender 材质、光照像素相同。

- 横版、竖版、自定义 900×700 的画布范围正确；竖版实测宽高比 0.5625，自定义比约 1.28571。
- 三个入口、返回后保留尺寸与视角、上次成品图提示及下载事件通过。
- 独立场景通过网页生成 512×512 透明 PNG，处理中设置与生成按钮禁用；成功自动进入查看器且无错误的过期提示。
- 临时移走独立场景源文件制造生成失败，确认页面保留 512×512、透明背景与上次成品图；恢复文件后再次生成成功。测试文件已恢复。
