# 作品首页与 Blender 入口

## 查找与继续

应用先显示作品首页，支持搜索、收藏、最近打开、排序，以及卡片/列表切换。首页使用保存的封面，点击“打开”才加载作品；返回首页后可继续当前工作台。

卡片菜单可重命名、收藏、移入回收站、查看文件和打开 Blender 源文件。回收站支持恢复，彻底删除有额外确认；活动任务和未结束的联动会阻止删除。

卡片上的 Codex 用量见 [Token 说明](TOKEN-USAGE.md)。未统计与不完整记录不会伪装成完整数值。

## 封面与文件

“刷新封面”按顺序读取模型并重新取景，只更新封面，不修改模型、材质或版本。单件失败保留旧封面并说明错误。尚未建模的作品没有三维封面。

文件侧栏集中展示当前模型、渲染图片、视频及已有的关联动画工程。文件缺失时显示不可用；源文件可以交给 Blender，媒体可预览或下载，文件也可以在访达中定位。

## 在 Blender 中打开

“在 Blender 中打开”启动独立 Blender 进程，读取当前 `.blend` 源文件，不要求安装 MCP。它不会自动刷新工作台的派生预览。

需要把 Blender 修改回传工作台时，使用 [MCP 联动](BLENDER-MCP.md) 的工作副本与同步流程。联动编辑与直接打开源文件是两个不同入口。

## 可选：Blender 的“我的作品”插件

源码安装方式：

```sh
npm run setup:project-library
# 卸载
npm run remove:project-library
```

运行前设置正确的 `ZAOWU_DATA_DIR` 和 `ZAOWU_BLENDER`。安装脚本备份已有插件和偏好，再启用插件；不要在 Blender 存在未保存偏好时执行。桌面安装包包含插件源码，但不会擅自安装或改写 Blender 偏好。

安装后在 Blender 顶部“我的作品”或侧栏“作品”浏览本地缓存。服务关闭时仍可打开缓存中存在的源文件；已有未保存场景由 Blender 原生保存/取消对话框处理。缓存不是模型副本。

缓存位于 `data/project-library/index.json`，只记录经后台校验的本地文件路径。`connection.json` 以当前用户读写权限保存随机端口、启动入口和本机作品列表凭据；该凭据只允许读取作品列表与建立相应会话，不允许进入桌面编辑接口。不要分享运行数据目录。

## 验证范围

文件归属、路径穿越、缺失文件、符号链接越界、离线源文件打开和原生未保存场景交接有隔离测试。UI 与发行包的实际结果见 [1.1 发布验收](releases/1.1.0.md)。
