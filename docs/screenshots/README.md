# 界面截图

1.1 主页使用 `v1.1-home.png`、`v1.1-workbench.png`、`v1.1-export.png`。它们由本版本实际 Electron 界面截取，示例作品由 `scripts/desktop-fixture.ts` 使用 Blender 创建，不含用户私人作品、账户或运行目录。

复现：构建桌面运行时后运行 `FORMA_DESKTOP_FULL=1 npm run test:desktop`；原始截图输出到 `build/desktop-evidence/`。发行前还应运行独立安装包验收，见开发指南。截图只证明当时的界面，不证明任意 AI 建模质量。

旧文件保留用于历史记录，当前主页已切换到 1.1 图片。

主页排版参考 [Excalidraw](https://github.com/excalidraw/excalidraw) 的产品展示与文档导航、[Cline](https://github.com/cline/cline) 的品牌首屏与下载入口；文案、图标和截图使用本项目内容。
