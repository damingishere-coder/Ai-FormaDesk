## 使用

刷新工作台，打开已保存作品，点击顶部 **Blender → 在 Blender 中打开**。网页变换/基础材质调整自动同步；在 Blender 中手工编辑后点击 **同步回工作台**。每次同步保存新的 `.blend` 和 GLB，保留原版本供撤销。

操作范围、恢复规则及接口见 [接入说明](BLENDER-MCP.md)。
