# FormaDesk 1.1.1 工程稳定性补丁

日期：2026-10-12。基于正式 main；沿用 Apple Silicon macOS、Electron 44.3.0、内置 Node.js 22.23.2 与 Blender 4.5 LTS。详细整改责任、回滚与限制见 [工程记录](../engineering/STABILITY.md)。

## 用户可见变化

- 第二个后台和维护 writer 在修改作品前拒绝占用同一 DATA；普通进程崩溃后重启可恢复，官方 ready 通知之后能立即正常退出。
- 模型已保存后，即使预览排队失败，也保持主任务和方案成功；可继续生成保存版本的预览。
- 切换作品时，旧同步、局部编辑、视频渲染、重试和取消结果不覆盖新任务；请求失去响应先核对状态，不盲目重发模型请求。
- 健康检查和 Blender 连接过期会明确提示；图片上传会话与请求等待有界。模态支持 Tab、Escape 与焦点返回。
- 复制或索引事务失败只补偿本次提交目录。成功事件在 SQLite 提交后发布，避免已回滚的任务显示成功。
- 合法 MCP 对象名包含错误关键词时不再误报；深层子树遍历按现有 1500 对象上限有界处理。

## 工程范围

提取 `artifacts` 与 `revision-commit`，打断 jobs 与 videos 的运行时循环；保持现有公开 artifact 接口、对象 ID、产物归属、版本与取消语义。未更换状态框架、数据库 Schema、AI 策略或材质/导出算法。

生产依赖补丁为 Fastify 5.12.5、MCP SDK 1.31.0、sharp 0.35.5，并定向更新受影响传递依赖。生产 npm audit 从 7 项降至 0；完整开发依赖扫描仍有 11 项（2 critical、9 moderate），位于 Vitest/tinypool/mocker 与打包工具日志链，不包含于桌面后端 runtime。升级测试工具主版本及更换打包链超出本轮同版本补丁范围；不将生产扫描结果说成整个工具链零风险。

默认浏览器回归使用独立无后台代理的 Vite，未 mock API/外部请求直接失败。真实浏览器与 20 个历史验收脚本必须显式启用并使用系统临时 DATA；真实 AI 还需额外启用。入口保护不代表旧 live 场景与 UI 断言已经全量实测。

## 验证与发布

正式包从合并后的干净提交构建，Release 提供 DMG、ZIP、SHA256SUMS 与 build-info。具体测试与发布结果在工程记录中列明；打包源码版本与是否 dirty 以 build-info 为准。

## 保留的边界

- 未使用 Apple Developer ID 签名或公证，仍为本机 ad-hoc 签名。
- 不保证任意照片建模质量、复杂场景长期视频性能、所有 macOS/GPU 或跨路径迁移。
- 已有作品与路径设置原位保留。文件系统与 SQLite 并非同一原子事务，硬退出可能留下提交标记；只读诊断不能自动决定删除作品。
- 本轮不实施 P2.5 大组件拆分、P2.6 Schema/兼容数据迁移或 P3 清理。
