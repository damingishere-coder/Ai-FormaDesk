## 已知边界

- 仅提供 Apple Silicon macOS 包；其他平台及最低系统版本未在本次逐一实机测试。
- 本机 ad-hoc 签名不等于 Apple Developer ID 签名或公证。
- 需要独立 Blender 与已登录的 Codex CLI；AI 需要网络和账户额度。
- 本次验证不重新声称任意图片建模质量通过，照片精确重建实验未并入。
- 实时视频验证短录制、保存与下载，未作复杂场景持续 60 fps 或长视频压力保证。
- 直接打开 `.blend` 不会自动重建工作台预览；工作副本同步使用可选 MCP。
- 数据索引含绝对路径，旧数据原位接入，任意路径迁移尚未支持。
