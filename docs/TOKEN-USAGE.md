# 作品 Token 用量

作品卡片在日期旁显示 Codex 累计用量，按十进制 K（1,000）、M（1,000,000）缩写。鼠标悬停可查看完整计数。

- 通过 `thread/tokenUsage/updated` 的 `tokenUsage.total.totalTokens` 保存每个会话的累计最大值，再按作品求和。重复通知、恢复会话和重复回填不会重复计入；缓存输入、推理输出已包含在总量中，不再相加。
- 覆盖讨论、脚本生成、视觉/材质处理和 Blender 局部修改。失败请求已经上报的用量仍保留。记录存入工作台 SQLite，重启、收藏、回收站恢复不会清零；彻底删除作品时随作品一起清理。
- 新作品在启用统计后从零开始。旧作品或缺少部分会话数据时显示 `≥`；没有可靠记录显示“Token 未统计”，不虚构零消耗。
- 仅表示 Codex 已上报的 token，不代表订阅额度百分比，也不包含图像工具单独计费的用量。

## 旧记录补回

在工作台数据目录与本机 Codex 数据目录配置正确的环境中运行：

```sh
npx tsx scripts/backfill-project-tokens.ts          # 只预览可恢复的会话数量
npx tsx scripts/backfill-project-tokens.ts --apply  # 写入作品用量记录，可安全重复运行
```

脚本仅按工作台已有作品/任务关联读取 Codex 会话的用量事件，不复制聊天内容或登录凭证。临时视觉会话未保存日志时无法补回，因此旧作品仍标注为部分统计。自动更新的新统计不依赖此脚本或 Codex 的历史索引。
