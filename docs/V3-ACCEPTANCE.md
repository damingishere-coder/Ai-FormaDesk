# V3：聊天布局、真实流程与视频

## 行为与实现

- 聊天窗口支持标题栏拖动、八方向拉伸、恢复默认布局和本机布局记忆。默认 720px / 75vh；窄屏宽度限制在视口内。短消息紧凑显示，输入框自动增高到 160px。
- 建模显示等待、脚本、Blender、验证、保存、预览六个阶段。阶段来自后台事件；预览完成来自对应版本的 GLTF 加载回调。自动修复显示轮次与错误记录，失败、取消和断线均保留状态。
- 时间估计使用最近 20 次同类成功任务的阶段耗时分位数，至少需要 5 个有效样本。冷启动的 2～5 分钟只是参考值，超过估计后显示超时提示，不制造百分比。
- 视频为固定输出尺寸，默认 1280×720 / 30fps / 最长 60 秒；单边 256～1920 且为偶数，无音轨、不透明。实时模式优先 MP4，不支持时使用 WebM；录制器会整理 WebM 的时长元数据。编码无法使用时，精细模式仍能记录和播放三维镜头路线。
- 视频画布只采集三维内容；录制期间锁定当前界面的编辑操作，退出恢复相机、选择和草稿。切入后台会停止并保留已有片段。
- 精细模式使用原始场景版本、带时间戳的镜头和 EEVEE。位置线性插值、旋转四元数插值，生成 PNG 帧序列后编码 H.264 MP4。任务取消或失败保留完成帧，续跑不覆盖只读输入场景；任务总时限为 2 小时。
- 视频随作品保留、回收和清理。上传期间阻止删除；服务端使用 Blender 解析实际媒体，校验归属、尺寸和时长。文件接口支持 HTTP Range，保证播放器可跳转。

## 接口兼容

新增项目 `videos` 创建、`videos/:videoId/upload` 上传、`videos/:videoId/render` 精细任务接口。镜头请求上限 2MB、视频上传上限 128MB；普通 JSON 保持 256KB。路径由服务端生成，上传只接受二进制媒体；场景快照新增可选 jobs/videos。任务事件增加阶段编号、轮次、阶段结束时间和帧数进度，旧事件仍可按阶段文字读取。

独立预览可设置 `ZAOWU_WEB_DIR` 指向构建目录；默认仍读取项目 dist。

## 验证证据

所有实际执行使用独立端口 18878 和 `data/v3-test`，不修改 8765 工作台的作品。证据产物在 `data/v3-evidence`，不提交视频、日志或数据库。

- **真实 Codex + Blender**：`real-job.json` 记录脚本生成、建模、模型验证、版本保存和完成事件。生成红色立方体、蓝色球体、黄色细柱，便于区分视角变化。
- **真实浏览器 MP4**：鼠标旋转、平移、缩放、停留，录制并保存 1280×720 MP4。`recording.json` 保存 47 个镜头采样，时长约 1.92 秒；并实际下载、解码关键帧。
- **WebM 兼容**：强制关闭 MP4 能力后真实录制 WebM，补齐时长后通过服务端解码和保存；模拟首次上传失败，保留片段后重试成功。
- **真实 Blender 视频**：使用同一镜头路线生成 58 帧 H.264 MP4；`blender-video-job.json` 保存完成状态。两种模式前后关键帧有明显运动，红色模型中心对应位置相差约 3 像素以内。
- **真实取消与重试**：`boundaries.json` 记录取消、保留帧、重新入队成功，Blender 日志确认复用 2 帧；跨项目版本／视频引用、错误尺寸、伪造媒体均拒绝；上传失败后重试成功，运行中删除拒绝，回收站恢复视频记录。
- **浏览器交互与模拟状态**：桌面 1195×762、窄屏 390×844 验证布局、输入增长、录制退出保留草稿；模拟脚本修复、超出估计、断线、失败及预览加载失败与重试。真实录制与模拟后端状态分别测试，不混作真实 AI 验收。
- **既有回归**：图片上传重试、粘贴拖入、临时预览隔离、上传中切换作品、讨论断线与取消通过。
- **数据清理测试**：回收站保留视频；人为制造清理目录符号链接后清理失败、状态保留，移除障碍后重试成功，其他作品文件保持不变。

单元／契约测试 18 项通过，V3 浏览器场景 4 项分组通过，既有浏览器回归 3 项通过；类型检查和生产构建通过。

复核命令：`npm test`、`npm run build`；浏览器运行 `npx playwright test tests/browser/v3.spec.ts`。真实视频脚本 `scripts/verify-v3-video.ts` 依赖第一项浏览器测试产生的录制轨迹；边界脚本为 `scripts/verify-v3-boundaries.ts`。完整浏览器套件会依次生成模型、实时视频、精细视频，再验证格式和异常状态。边界脚本在浏览器套件之后运行；独立精细视频脚本用于单独复核同一轨迹。

## 开源参考

实时采集参考 [canvas-record](https://github.com/dmnsgn/canvas-record) 的画布和 MediaRecorder 方案；使用浏览器原生接口，没有引入完整录制框架。WebM 元数据整理使用 MIT 许可的 [fix-webm-duration](https://github.com/yusitnikov/fix-webm-duration)。保留依赖许可证。

## 限制

实时录制的实际帧率受浏览器、窗口前后台状态和场景负载影响，30fps 是采集目标；精细输出为固定 30fps。精细视频速度取决于模型复杂度，进度从已渲染帧计算。浏览器真实验收使用本机 Chrome；未将这些结果声称为所有浏览器、60 秒上限或 1920px 复杂场景压力测试。
