# 多模态创作工作台验收

## 交付行为

- 文字与 PNG/JPEG/WebP 图片共同讨论；文件选择、拖入、粘贴截图，支持每条最多 6 张、单张 10 MB、合计 40 MB。服务端完整解码，限制 2500 万像素；图片纠正方向并以无元数据 PNG 保存。
- 消息发送只触发讨论，独立方案卡按钮执行建模。方案绑定版本、目标对象和参考图片，新讨论或版本变更使旧方案失效；重复点击复用任务。
- 聊天记录从底部输入框向上展开，独立滚动；不抢夺正在翻看历史的用户滚动位置。作品临时预览不切换编辑项目或清空草稿。
- 预览模式可旋转、平移、缩放，编辑/预览切换保留相机；渲染出图与导出共用尺寸、比例和透明背景设置。成品图单独查看，可下载旧图并看到原有参数。
- 作品库支持新建、重命名、只读三维预览、回收站、恢复和确认彻底删除。有活动任务的作品禁止删除，删除当前作品返回选择页。

## 可重复检查

先在独立终端启动验收后台（不要对同一数据目录启动两个后台）：

```sh
npm run build
ZAOWU_PORT=18877 ZAOWU_DATA_DIR="$PWD/data/v2-acceptance" npm start
```

随后运行：

```sh
npm test
node --import tsx scripts/verify-v2.ts
node --import tsx scripts/reopen-v2.ts
npx playwright test tests/browser/v2.spec.ts
FORMA_REAL_AI=1 npx playwright test tests/browser/v2.spec.ts -g '真实浏览器'
ZAOWU_DATA_DIR="$PWD/data/v2-regression" npm run test:integration
```

`verify-v2` 和“真实浏览器”会创建新验收作品并使用现有 Codex 账户额度。普通 V2 浏览器用例使用真实本地项目、上传和回收站接口；仅上传失败、最后一个作品列表和捕获相机的渲染请求采用拦截模拟，这些不代表真实渲染证据。

当前自动化结果：`npm test` 12/12 通过；V2 浏览器 6 项均分组通过（其中一项包含真实 Codex/Blender，一项明确模拟断线，另一项覆盖上传中切换作品）；既有 Blender 集成检查 6/6 通过。排队取消与删除竞争已增加专门回归测试，保证取消后立即可重试、彻底删除后队列不会重新写入记录。

单元测试使用系统临时目录验证损坏图片、像素/大小/数量限制、跨项目引用、回收站恢复、活动任务删除拦截、符号链接保护、清理失败重试、24 小时孤立附件清理及重启恢复。截图和模型属于运行产物，保存在忽略的 `data/v2-evidence` 中。

## 兼容与边界

旧项目及对话继续读取；旧渲染缺少设置时按 1280×720、不透明解释。模型与讨论分别保存 Codex 会话，保持现有登录、提供商和 Astra/high 设置。图片是建模参考，不自动成为表面纹理；网页实时材质是近似预览，Blender 成品图是最终渲染。

彻底删除仅清理项目所属本地数据，不删除全局 Codex 会话；已发送图片随作品保留，未发送图片超 24 小时清理，回收站中的图片保留到恢复或彻底删除。删除/恢复不会自动开始任务。项目的实体文件没有复制迁移，现有保存版本仍然不可变。
