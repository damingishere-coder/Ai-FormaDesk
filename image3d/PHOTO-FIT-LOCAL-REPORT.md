# PhotoFit V2 阶段 A 本机实测

日期：2026-09-08。结论：**纠错机制在 2/4 个固定样本上有效，阶段 A 门槛未通过，V2 未完成。**
建筑、椅子、盆栽、用户猫咪均保留原样本，没有用其他图片替换失败项。
椅子在两条路线均改善，仍只算一个样本。猫咪只有胸腹局部改善，整体还原质量未达标。
所有输出均为实验候选，没有采用到正式作品；用户认可的类别数量为零。

## 修正及失败原因

- 椅子脚本：加宽坐垫前部、调整栏杆和腿宽、椅背顶缘和前脚间距；两轮通过数值及前后视觉检查。
  底模路线收回左侧椅背外扩、减轻顶横板下凹，并调整坐垫；第一轮保留，第二轮无改善而拒绝。
- 猫咪脚本：第一轮腹部扩张遮吞后肢轮廓，自动回退；第二轮胸部加宽及下延通过局部改善检查。
  GPT 整体判断仍为 `acceptable=false`。脸颊与口鼻分块、胸腹椭球叠接、前腿细长及后肢支撑关系仍不符合原照。
  主控查看实际灰模也确认这些缺陷，不能称为照片级猫咪建模。
- 建筑：底模门窗与墙面严重融合，局部平滑无法重建结构；脚本调整屋顶后轮廓指标未改善。
  树叶遮挡干扰轮廓目标，现有机制还缺少遮挡区域剔除及门窗结构对应。
- 盆栽：底模叶片大面积粘连，系统拒绝仅用平滑/形变修复。脚本路线虽然降低轮廓误差，
  但扩盆沿连带导致盆壁折陷，视觉复核连续两次拒绝，保留原候选。叶冠侧面仍过扁。

## 验证

- TypeScript 检查、18 项单元测试与 Vite 构建通过。构建仍提示既有大 bundle 与 Zod PURE 注释警告。
- 真实 Blender 受控验证通过六组检查：已知比例错误恢复、参数范围及稳定 ID、局部范围外不变、
  UV/拓扑/变换/共享网格隔离、非法输入拒绝、薄叶及放样/重复结构与真实可见锚点。
  主动压缩宽度 30% 的样本，固定相机轮廓误差从 0.2999185 恢复到 0。
- 真实故障验证通过：人为低内存上限触发进程终止、短超时、启动后取消，随后资源锁可再次获取。
- 既有 Blender 集成六项通过：沙箱文件/网络隔离、GLB 和层级、材质隔离、错误脚本不覆盖作品、取消及串行调度。
- 尚未执行完整工作台 UI、图片和视频导出浏览器回归；本阶段没有修改这些界面。
- 静态对比页通过已安装 Chrome 的独立无头浏览器检查：八组对比、八个 GLB 链接、所有图片加载成功，
  1440/390 像素宽度均无横向溢出、无页面脚本错误；主控查看桌面截图确认版面。
  Playwright 自带浏览器缺失，使用本机 Chrome 完成此检查，没有更改用户浏览器会话。
