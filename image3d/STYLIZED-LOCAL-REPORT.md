# V2.1 本机实测：阶段 A 未达到准入门槛

日期：2026-09-08。环境：MacBook Air M2 / 16 GiB，Blender 4.5.13 LTS，既有 Codex 登录、`gpt-6-astra` / `high`。本次是脚本实验，不调用 Hunyuan 或 StableGen 推理。

## 结论与实施范围

已实现特征契约、参数化连续形体、两种力度的局部纠错、范围检查、候选保留、标准材质上色和独立对比页。四个固定样本均真实执行、保存 `.blend`、重新打开并导出 GLB；猫咪和盆栽的参数修改实际执行并获得有限改善。

**自动整体检查仅椅子通过，1/4；没有任何用户质量认可。阶段 A 的“至少三例通过且猫咪获用户认可”未满足，B/C 未实施。** 独立对比页不是工作台新增功能，旧失败没有改标通过。

## 已验证的机制

- 真实 Blender 连续场与融合测试：闭合连接、浅眼部贴面法线、眼部排除融合、绝对 ±15% 参数范围、拒绝漂移与非有限值。
- 真实已知错误：GPT 从图像提出宽度 0.86 → 1.0；Blender 执行后宽度误差 0.14 → 0，非目标标记保持不变。这证明受控纠错有效，不证明照片质量通过。
- 上色保持网格、UV、ID，未选区域不变；GLB 重新导入保留标准色板区域。
- 面序变化测试：允许无语义变化的面片排列；仍拒绝实际 UV 顶点角变化，避免虚假的非目标修改报错。
- 真实内存超限、超时、取消及资源锁释放测试通过；现有六项集成验证通过，覆盖脚本文件/网络沙箱、GLB、材质隔离、坏脚本、取消与串行调度。
- 旧 `photoFit` 六组受控 Blender 回归通过。23 个单元测试、TypeScript 检查和前端构建通过；构建仍有既有依赖注释及大包警告。
- 独立对比页的真实 Chrome 检查通过：四个 GLB 下载字节与文件一致、均低于15万三角面、拖动旋转有效、移动窄屏无横向溢出、页面无异常。往返切换后 WebGL buffer/texture 数量回到 59/4，没有本次切换累积；这不是长期资源泄漏或完整工作台回归的证明。

## 保留的失败与版本差异

- `stylized-batch-01` 四例在 JSON Schema 元组兼容性处失败，未执行 Blender。已修复结构化响应的数组描述。
- `stylized-batch-02` 猫咪有明显球体拼接、凸眼；完成后停止该批的后续生成。结果仍保留。
- `stylized-batch-03` 猫咪虽统一体素融合，仍有头颈、肢体接缝。盆栽生成触发旧 10 分钟单次上限。
- `stylized-cat-04` 脚本生成也触发旧 10 分钟上限，未执行 Blender。
- 后续增加有界连续场与浅贴面；脚本生成上限改为 `min(剩余预算, 15分钟)`，其他旧路线默认仍为 10 分钟。
- 建筑与最初椅子使用旧的中间候选接受策略；猫咪、盆栽末次使用“目标改善且无退化即可保留中间候选”。所有运行记录保存代码哈希，不宣称它们使用完全一致的实现。
- 彩色检查增加中性环境补光，避免把接近黑色的默认环境误判为配色失败；椅子单独重查并保存父记录。这个变化不计为几何改善。
- 最终代码还向视觉检查提供部件 ID、包围盒与参数清单。该提示补充通过类型检查，但未重跑整套样本；不会据此改写本次检查结论。

## 仍需解决，才能进入阶段 B

1. 初始脚本须暴露真正对应问题的控制参数：猫咪后肢连接、吻部和眼部大小；植物扇组朝向和前后位置；建筑转角窗关系。不能靠扩大现有无关参数范围通过检查。
2. 有限的椭球选面色块会产生硬边和锯齿，尚未实现计划中的通用色块曲线及复杂纹理烘焙。需要改善主要花纹表达，并继续保持网格不变。
3. 比例上限目前约束脚本声明的照片基准，不能证明基准估计本身准确；需增强关键比例与照片分析之间的关联。
4. 尚未实现正式 `stylized` 生成/精修 API、风格编辑、候选采用与版本冲突、跨任务恢复、五类十图验收及完整工作台浏览器回归。
